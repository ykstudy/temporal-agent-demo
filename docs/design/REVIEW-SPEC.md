# Vue 工作区与设计审查页面规范

日期：2026-10-02。用户已授权推进 Vue 等价迁移、审查模型、审查页面及浏览器和图片验证。业务规则以根 design 和公共契约为准；图形不授予运行权限。

## 视觉依据

[审查页概念](review-workbench-concept.png) 由内置 imagegen 生成；参考 process-diagram 的分类目录、独立 SVG 画布与可收起详情栏。概念只决定视觉组织，图内示意字段和连线不是契约真值；正式字段、基数与绑定从发布 Schema 和来源规范读取。概念中的 approved_scope、verified_version、artifact_version 等示意词不进入目标对象。

提示摘要：1600×1000 横向中文只读审查工具，冷灰外壳、白画布、海军蓝正文、靛蓝控件；11 项类型目录，完整契约链 SVG，右侧说明/元素/来源，缩放、适应与 SVG/PNG 导出；无运行成功统计或生产权限。

## Tokens 与布局

背景 #f5f7fb，画布 #ffffff，正文 #20263e，辅助 #6d7890，分隔 #e3e7f0，强调 #6265e8。节点仅按语义用浅紫、薄荷、琥珀区分；未知/未执行不得染成成功。

系统/PingFang 字体；页面标题 26/650，正文 15/1.7，控件 14/550，辅助 12/1.6，图内文字使用各图原生 SVG 字体层级。图标采用 Lucide 20px/1.8，真实按钮保持键盘访问。

头部约 64px；左目录 220px，右说明约 290px，可收起；主体为完整原生 SVG 与底部视口工具。默认打开契约对象，可从目录切换。大图通过缩放平移阅读；移动端目录和说明进入独立抽屉，画布保持完整源范围，没有页面级横向溢出。

## 页面与文案

入口为 `?review`；独立视图为 `?review=state` 等发布模型 ID。未知 ID 返回明确的类型选择提示。顶部为 Agent Studio / 设计审查、返回工作区、切换主题、导出 SVG、导出 PNG；目录提供搜索和类型分组。

11 类导航：状态与门禁、职责与权限、交互时序、契约对象、来源与证据、模块边界、验收覆盖、身份与版本、文档关系、Skill 能力、上下文与摘要。右侧包含审查说明、选中元素、来源文档；用户可读取路径、摘要及原文。正文增加的语义筛选、转移表和状态图例只服务准确审查，不添加假统计或产品执行按钮。

文档关系图按真实 domain/feature/ADR/invariant 与已登记关系生成，默认按域收敛，能筛选类型和关系。不能全量展示成不可阅读线团。验收覆盖使用离散状态矩阵，不将结构校验或历史路径 passed 统计成 v2 完成比例。

## 功能与验收

现有工作区保持创建、消息、预览、批准/修订/拒绝、暂停/恢复/取消/重做、SSE、产物/历史/ZIP 及窄屏行为。迁移修复异步 Run/草稿污染与生命周期清理；API 保持 legacy，迁移不代表已实施 v2。

审查页只读发布 bundle；模型/来源先通过结构、身份、端点、来源摘要和范围校验。来源查看、节点/关系详情、搜索/筛选、主题、缩放/平移/适应、说明收起、独立链接和 SVG/PNG 下载都须可实际操作。

导出源是同一份原生 SVG，与当前视口变换独立。导出包含基线、契约版本、生成时点、模型身份和 source digest；PNG 附 PNG 文本 metadata，完整图形/连线必须可见。图上保留设计/current/evidence 范围，禁止把归档状态当执行许可。

验证分为模型与来源校验、构建类型检查、原工作区浏览器路径和竞态回归、11 视图交互及真实导出。审查可视化与 Vue 迁移结果单独登记；原 v2 C01–C18 与 live 第三方状态不继承。本次最终截图需与概念及参考工作台比对配色、布局、文字、控件、图形/连接、移动端与导出完整性。


## 实施收敛

正式图按来源规则选择语义：默认契约视图为八对象、七条核心字段绑定链；全部对象开关展示完整 Schema 投影。前三/四个字段仅作名称摘要，完整类型、必需性和约束在来源详情。箭头始终保持引用方到被引用方，不能照概念示意改变来源方向。移动的关系标签带虚线引线，不伪造额外业务边。

发布束和 Schema 的原字节摘要固定进构建。浏览器先验证摘要，再验证编译规范、冻结基线与来源；来源相同但图投影被删改也拒绝。来源弹窗限定焦点并在关闭时返回；移动端有可达的说明关闭和工作区返回。画布在按下时捕获拖拽，松开、失焦或捕获丢失后停止平移。
