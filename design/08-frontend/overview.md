# 前端交互域

> 实体ID：domain.frontend
> 基线日期：2026-10-02。
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§3、§5.4、§10、§12；审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)：R-002、R-011、R-022、R-023、R-024。

## 域职责

定义用户看见和操作的对话工作区、方案及模型审阅、阶段与工件面板、状态同步和可访问交互。将权威服务端契约呈现为可理解的消息、等待原因、批准范围和交付证据，保持多 Run 归属。

## 域边界

前端是权威状态的投影与命令入口，不承担 Workflow 状态迁移、权限批准、预算检查或外部副作用。自然语言、按钮动画与本地编辑不构成执行授权或完成证据。结构认知模型与运行 Task DAG 分开；界面不提供生成项目的生产发布。

## 与其他域的关系

消费会话消息、预览确认和工件浏览公开契约，提交版本绑定命令给人类关卡；从编排与可观测性读取阶段、回执和证据，从治理与运维取得权限、模式及能力状态。所有展示都注明 local/temporal 与 rules/model，缺配置和断线保持可见。

## 按改动节奏划域的理由

布局、阅读方式、键盘操作、响应式行为与状态反馈随用户路径迭代，其节奏不同于合法阶段、技能算法和第三方协议。独立前端契约允许交互改善而不改变服务端授权，同时固定刷新、重连和审阅的可验证行为。
