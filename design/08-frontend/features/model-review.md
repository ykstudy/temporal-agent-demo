# 功能：模型与提案审阅

> 实体ID：feature.frontend.model-review
> 来源：[原设计](../../../docs/PRODUCT-GUIDE.md)：§2.1、§2.2、§4.1、§5.1、§5.2、§9。
> 审校：[裁决记录](../../../docs/analysis/REVIEW-DECISIONS.md)：R-010、R-011、R-012、R-019、R-024。
> 基线日期：2026-10-02。

原文说明版本配置与模型决策，没有提供结构模型编辑界面；本篇补充审阅目标。当前按ADR-047迁移Vue对话工作区并实现独立只读审查；文档模型编辑仍为后续目标；早期实验认知API已按ADR-045移除，本视图仍为规范目标，离线检查不提供运行批准。

## 目标

帮助用户审查文档结构、创建提案及其影响，区分模型建议、确定性校验、人工确认与实际应用。文档模型只形成单用户本地审阅版本；认知结构不成为运行 Task DAG、权限来源或完成判据。

## 输入

接收当前来源与模型版本、结构实体关系、拟议差异、影响范围、校验结果及未应用提案。文档变更带 scope/base_version；运行确认带提案身份、版本、源版本、用户、操作范围和有效期。决策模式 rules/model 单独标示。

## 输出

呈现可比较的原值与拟议值、受影响公开契约、校验问题及服务端许可的操作入口。审阅状态分别为建议、待确认、已批准、应用中和已有权威结果，不能将其中任一前态显示为应用成功。

## 算法 / 流程

本阶段只读投影按[审查模型规范](../../review/MODELS.md)加载本项目生成的bundle，提供十一图、来源详情及同源SVG/PNG导出；不提供下述设计apply或回退入口。

加载权威版本与范围后展示差异和来源，先取得约束结果再提交版本绑定确认。文档 apply 通过版本 CAS 形成本地审阅新版本，回退也产生新提案；运行确认独立提交人类门控。跟踪同一命令回执，仅权威应用结果刷新对应范围版本。浏览器编辑、自然语言或模型自报完成均不更新记录。

## 边界与异常

来源变化作废旧确认，冲突展示新差异，重复确认返回既有结果。冻结不变量、权限或不支持字段的修改被拒绝，不隐藏失败校验。文档 apply/回退不运行项目、改变 Run 批准或撤销仓库/CI 事实。审批和应用结果等待权威服务端，本产品没有生产发布入口。

## 被谁依赖


当前基线无其他功能消费本契约；入口/外部使用者在该功能输入与验收中说明。

## 验收标准

本阶段十一类模型及每个元素来源可复核，design/current/evidence和历史时点明确；前端运行不触发checker或写API。SVG/PNG与同一图数据一致，包含模型和冻结基线标记。

旧版本、过期、重复和冲突确认均呈现服务端裁决；校验失败不能通过隐藏按钮或修改客户端状态绕过。已批准但尚未应用时不显示成功，刷新后版本与回执一致；rules 与 model 的建议来源明确，文档关系图不能被称为运行 DAG。
