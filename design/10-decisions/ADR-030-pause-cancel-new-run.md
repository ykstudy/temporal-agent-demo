# ADR-030 暂停安全边界生效且终止重做新 Run

> 实体ID：adr.ADR-030
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§5.4、§8、§13；R-022。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)。

## 状态

accepted（2026-10-02 本次审校后的有效设计基线；不是已实现状态）。

## 背景

§5.4、§8、§13；R-022。原文保留为证据。当前项目的目标与参考方法不同，本记录对原文已述选择、冲突或缺口做明确裁决；原作者未记录的理由和备选不追溯编造。

## 决策

暂停记录请求，在不可逆阶段安全边界生效并保存 resume_to；恢复复校来源、授权与预算。DONE/FAILED/CANCELLED 终止后只读和核实既有事实；重做生成关联新 Run、新预览和批准。拒绝未应用提案回 CLARIFY。

## 理由

本次评估：取消和进程停止不会消除已发生的外部写；终止重开容易继承过期批准；拒绝方案不等于取消业务目标。

## 备选方案

以下为本次评估，不表示原作者曾讨论：立即杀所有子进程并宣称回滚：外部结果未知；原地复活终止态：历史和批准混淆；拒绝就永久终止：无法修订需求。

## 影响

暂停显示申请中和已暂停区别；未知结果优先 BLOCKED；新 Run 保留原任务关联与证据，普通 retry 不绕过授权。 领域只通过下列功能的公开输入/输出协作，运行行为由后续独立验收证明。
