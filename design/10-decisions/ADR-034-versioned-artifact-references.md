# ADR-034 大对象采用可验证工件引用

> 实体ID：adr.ADR-034
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§4.3、§6.1–6.2；R-018。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)。

## 背景

§4.3、§6.1–6.2；R-018。原文保留为证据。当前项目的目标与参考方法不同，本记录对原文已述选择、冲突或缺口做明确裁决；原作者未记录的理由和备选不追溯编造。

## 决策

Workflow payload 保存小体积身份、版本、摘要和工件引用，正文/ZIP/对话从外部存储读取；引用绑定 run/source、内容 hash、大小和访问规则，必须在接替 Worker 可访问。预览来源与实际落盘工件分别显示。

## 理由

本次评估：Temporal 历史不能承担大对象反复传递；本机路径无法保证跨节点恢复，未经归属校验的预览还可能暴露其他 Run 文件。

## 备选方案

以下为本次评估，不表示原作者曾讨论：所有文件正文写 Workflow history：体积失控；裸路径无hash：内容可漂移；只有 UI 截图：无法检查真实产物。

## 影响

需要长期有效引用和存储恢复契约；失效明确不可用；下载验证同 manifest，路径和文件类型白名单保护浏览。 领域只通过下列功能的公开输入/输出协作，运行行为由后续独立验收证明。
