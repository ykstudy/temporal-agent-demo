# ADR-012 三项 Skill 注册与参数 Schema

> 实体ID：adr.012
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§2.3、§7.2、§9.2；L65–81、L877–920、L1212–1216。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)：R-010、R-017、R-020。

## 状态

accepted。生效日期为 2026-10-02；这是本次有效设计基线，不将来源示例、已有代码或测试结果追认为过去的批准。

## 背景

原文列出 add_database、add_auth、add_logging 与部分参数，但执行示例仍通过文件标记跳过，未明确版本、兼容组合和工具权限。已登记名字不意味着所有参数与任意实现都获得授权。

## 决策

首版只注册三项 Skill，每个版本同时声明支持栈、参数 Schema、默认值、输入输出、写路径、工具许可、前置条件和验证要求。选中技能必须有显式参数解析和组合兼容判定；未知技能及未登记能力拒绝执行。

## 理由

完整契约能让模型建议、预览、执行和验收使用相同能力边界。Skill 的可复用性来自输入输出和版本控制，而不是动态 shell 或生成后默认存在的文件名。

## 备选方案

把参数作为无约束 map 易遗漏默认和拼写错误；将每个技能写死在界面使后端能力漂移；运行时加载任意脚本会扩大执行权限。采用版本化注册和白名单。

## 影响

变更参数 Schema 或输出范围要更新技能与模板版本，旧 Run 继续使用快照。验收合法和非法枚举、重复技能、冲突组合、参数改变后的重新应用，以及缺权限时不生成部分成功记录。
