# ADR-007 动作 Schema 校验与工具白名单

> 实体ID：adr.007
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§2.3、§5.2、§9.2；L65–81、L418–530、L1212–1216。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)：R-010、R-020、R-021。

## 状态

accepted。生效日期为 2026-10-02；这是本次有效设计基线，不将来源示例、已有代码或测试结果追认为过去的批准。

## 背景

原文直接 switch action，未知动作没有明确拒绝结果，参数和工具能力也未闭合。若把模型字符串或 JSON 能解析等同于合法动作，未登记技能和任意命令可能进入执行器。

## 决策

动作先经过版本化 Schema、动作白名单、字段类型/枚举/长度、状态前置条件、依赖、权限、预算和批准范围校验，再转换为受控调用。未知动作、多余执行字段和越界参数明确拒绝；修正建议不直接拥有执行权。

## 理由

结构校验证明请求形状，业务规则证明在当前版本下允许执行，两者缺一不可。统一入口使 API、模型和恢复命令使用同一裁决，避免通过另一路径绕过检查。

## 备选方案

仅依赖 JSON 解码无法约束业务语义；在各 Activity 临时补校验容易不一致；无限请求模型修复会耗尽预算。采用集中判定，执行器仍复核其资源与目标边界。

## 影响

拒绝结果包含稳定原因和可修改字段，错误不触发副作用。测试覆盖未知 action、非法枚举、缺字段、错误状态、旧批准、路径逃逸和修正预算耗尽，确保每项拒绝都保留审计归属。
