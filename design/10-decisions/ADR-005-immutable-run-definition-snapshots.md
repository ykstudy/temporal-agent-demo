# ADR-005 固定运行 Definition / Template / Skill 快照

> 实体ID：adr.005
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§2.1–2.3、§7.1–7.2；L26–81、L778–802、L867–915。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)：R-011、R-017。

## 状态

accepted。生效日期为 2026-10-02；这是本次有效设计基线，不将来源示例、已有代码或测试结果追认为过去的批准。

## 背景

原文要求 AgentDefinition 版本化且运行中不漂移，但审批和 Activity 输入未绑定模板、技能及工具版本。Worker 更新后重新读取最新模板，会使恢复执行偏离用户已经审查的差异。

## 决策

每个 Run 创建不可变定义引用，含 AgentDefinition、模板、Skill、动作 Schema 与工具版本；提案另绑定参数摘要、来源版本及渲染文件快照。确认后执行这些已批准内容，不能在应用时重新选择最新注册项。

## 理由

不可变引用让审查结果、恢复过程和最终 manifest 对应同一来源。保存文件 hash 与版本可区分升级、参数修改和存储损坏，而不是把完成标记当成全部证明。

## 备选方案

只存版本名容易遭到同名覆盖；只固定系统提示词仍允许模板漂移；每次执行取最新版本使批准失效。为方便升级牺牲审查一致性不属于允许例外。

## 影响

定义仓库必须可获取旧版本或其完整摘要快照，恢复先核验内容。更换版本创建新提案或新 Run；验收在待确认和执行中升级 Worker，旧批准产物保持原样，缺失快照明确阻塞。
