# ADR-036 对话为入口并列展示进度和产物

> 实体ID：adr.ADR-036
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§3用户侧、§5.4、§10.1；R-023–024；参考对话后续产品展示建议。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)。

## 状态

accepted（2026-10-02 本次审校后的有效设计基线；不是已实现状态）。

## 背景

§3用户侧、§5.4、§10.1；R-023–024；参考对话后续产品展示建议。原文保留为证据。当前项目的目标与参考方法不同，本记录对原文已述选择、冲突或缺口做明确裁决；原作者未记录的理由和备选不追溯编造。

## 决策

采用单会话主入口，当前 Run 进度与产物并列，版本/确认/错误清晰显示；设计依据和模型关系按需查看。客户端只发意图，消费服务端权威状态；多 Run 切换不改变原消息归属，失败保留草稿。

## 理由

本次评估：参考对话强调用户先理解目标、进度和需要决定的内容；目前仅setup不是成品，文档应描述用户行为而非把设计图当实现证据。

## 备选方案

以下为本次评估，不表示原作者曾讨论：首页堆全部领域模型：掩盖任务；客户端自行推进：权限/版本漂移；只显示模型回复：缺确认与真实交付判断。

## 影响

桌面/移动与可访问性形成独立验收；状态流中断和用户等待区分；具体框架/视觉草案不冻结成产品业务契约。 领域只通过下列功能的公开输入/输出协作，运行行为由后续独立验收证明。
