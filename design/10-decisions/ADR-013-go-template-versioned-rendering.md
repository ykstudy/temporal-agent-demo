# ADR-013 Go template 渲染与模板版本

> 实体ID：adr.013
> 来源：[原设计](../../docs/PRODUCT-GUIDE.md)：§1.2、§7.1、§7.2；L15–18、L770–858、L877–920。
> 审校：[裁决记录](../../docs/analysis/REVIEW-DECISIONS.md)：R-011、R-017、R-020。

## 状态

accepted。生效日期为 2026-10-02；这是本次有效设计基线，不将来源示例、已有代码或测试结果追认为过去的批准。

## 背景

原文使用模板生成目录并检查完成标记，没有对模板内容、参数和所生成文件建立版本证明。缺变量、错误路径或后续模板升级都会使相同用户输入得到不同文件。

## 决策

采用 Go text/template 作为确定内容渲染引擎，模板包不可变并登记版本与摘要。输入先经 Schema 校验，缺必需变量或渲染错误立即失败；模板只渲染获准文件，不执行网络、命令或扩大路径，产物先进入隔离 staging。

## 理由

成熟模板语法适合可审查的 Go 骨架且可脱离模型复现。把参数解析、内容渲染和副作用提交分开，能比较预览与实际工件，也能准确判断恢复时是否沿用原批准。

## 备选方案

完全依赖模型逐次生成提高自由度却难以复现；无版本字符串替换容易误替换；模板函数调用任意外部工具使渲染具备隐藏副作用。扩展函数须受控登记。

## 影响

Go 工具链、模块依赖与模板内容一起留在来源 manifest。验收相同快照重复渲染 hash 相同、未知字段拒绝、模板缺变量失败，以及 Worker 更新后旧提案生成内容仍与预览一致。
