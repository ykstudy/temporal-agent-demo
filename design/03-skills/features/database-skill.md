# 功能：数据库技能

> 实体ID：feature.skills.database-skill
> 来源：[原设计](../../../docs/PRODUCT-GUIDE.md)：§2.3、§7.2、§7.5；L71、L877–920、L1122–1147。
> 审校：[裁决记录](../../../docs/analysis/REVIEW-DECISIONS.md)：R-009、R-017、R-020。
> 基线日期：2026-10-02。

## 目标

首版为 Go 项目生成数据库连接、ORM 配置与迁移入口，支持 PostgreSQL、MySQL、SQLite 与 GORM/sqlx。能力限定代码生成和隔离测试，不在客户数据库执行真实连接验证或迁移。

## 输入

已确认 Skill 版本、database_type、orm、连接配置结构、迁移入口策略、固定驱动/模块、scaffold/workspace/manifest 与允许命令；隔离测试另带测试目标及临时凭据引用。默认 PostgreSQL/GORM，候选须显式选择，应用身份与参数 hash 关联方案。

## 输出

适配器、配置示例、迁移入口/说明、测试与依赖 manifest，以及不支持组合/缺配置结果。报告区分生成编译、隔离连接/迁移测试和客户目标未执行，隔离通过不证明客户数据库可用。

## 算法 / 流程

1. 按公开 Schema 验证数据库/ORM 组合和支持平台，选择固定驱动/模板版本；不注入默认密码或真实 DSN。
2. 生成连接、生命周期/错误处理、配置读取和可审查迁移入口，与基础项目入口协作；未配置时采用明确未连接状态。
3. 以受控命令整理依赖并运行缺配置/连接失败等测试，记录 SQLite CGO/运行镜像等兼容要求。
4. 仅在登记的隔离测试 DB 验证连接/迁移逻辑，测试身份与数据可销毁且范围受控；交付代码、测试报告和客户运行说明，禁止用普通项目确认访问客户 DB。

## 边界与异常

编译不证明客户 DB 可访问，缺测试配置不得伪报连接成功。客户目标真实连接/迁移属于未来扩展，须新 ADR、精确 DB 目标及独立批准/核实契约；首版拒绝该动作。参数改变不复用旧 marker，测试不继承执行器凭据，DSN/错误脱敏。

## 验收标准

六种组合逐项编译/测试，未支持组合拒绝；隔离 DB 登记测试目标、临时凭据引用和结果，缺配置不能伪报健康。用客户 DSN 或普通接受请求真实迁移必须在连接前拒绝；扫描代码/日志/ZIP 无秘密，重复生成不重复隔离副作用。
